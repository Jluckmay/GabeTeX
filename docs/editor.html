GabeTeX Online Editor

Edit LaTeX source on the left, preview the compiled output on the right. Compilation happens on the backend; only LaTeX source and rendered results travel between frontend and backend.

Security measures

Same-origin onlyFrontend and backend communicate exclusively with each other; no third-party endpoints.
CSP enforcedContent Security Policy restricts scripts, styles, and connections to trusted sources.
Input sanitizedLaTeX source is validated before compilation; dangerous commands are blocked.
Sandboxed compileCompilation runs in an isolated container with no network or filesystem access beyond the working directory.
Rate limitedCompilation requests are throttled to prevent abuse.
No code executionThe backend never evaluates user input as code; it only pipes LaTeX through a fixed compiler binary.
